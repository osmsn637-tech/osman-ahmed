# QEU WMS App Releases

Official release repository for the QEU warehouse applications.

## Downloads

Download the current applications and update manifest from the
[putaway release](https://github.com/osmsn637-tech/osman-ahmed/releases/tag/putaway).

- `putaway_app.apk` — Android warehouse worker app
- `putaway_app_inbound.zip` — Windows inbound application
- `scan-dpc-mdm.apk` — Android device-management agent
- `version.json` — application update manifest
